夸克网盘 × PotPlayer「边下边播」完整方案

适用：Windows 10/11 · PotPlayer · 夸克网盘（SVIP） · 2026-09
一句话结论
夸克官方不提供 WebDAV，想用 PotPlayer 边下边播必须靠第三方桥接。最省事且免费的主路线：OpenList（Alist 社区版）拿直链 → PotPlayer 直接播 URL；想在资源管理器里双击就播，再叠加 rclone 挂载成 Z: 盘；完全不想碰命令行，就选付费的 CloudDrive2。

① 三种实现方式对比

方案原理双击播放成本优点缺点
A. OpenList 直链 + PotPlayer 播 URL推荐起步 OpenList 把夸克转成 HTTP 直链（302 到夸克 CDN），PotPlayer 打开 URL 流式播放 ✘（靠脚本/协议代劳）免费开源 10 分钟跑通；不占本地磁盘；直链走 CDN 满速；一条命令即可自动化 资源管理器里没有实体文件；外挂字幕要手动载入
B. OpenList + rclone 挂载盘符要双击就加 rclone 通过 WebDAV 把 OpenList 挂成 Z: 盘 ✔ 原生双击免费开源 双击即播、字幕同名自动加载、可当普通盘用 多装两个组件（WinFsp + rclone）；缓存占磁盘；seek 首次略慢
C. CloudDrive2付费 商业软件内置夸克驱动，直接挂盘符 ✔ 原生双击订阅制（价格以官网为准） 图形界面全自动，最省事；还能做 WebDAV 服务器 要钱；闭源
D. 夸克官方客户端「在线播放」 夸克自家播放器，转码流 ✘免费 零配置、不折腾 不能用 PotPlayer、不能选外挂解码、清晰度受限于转码

推荐路径：先做 A（验证链路 + 日常“丢个链接就能看”），顺手把 B 的挂载配上（双击体验）。C 仅在你完全不想碰命令行时选。

⚠️ 合规与账号风险（必读）
夸克用户协议禁止“自动化访问及非授权集成”。OpenList/CD2 都是通过网页版 Cookie 模拟登录实现的第三方接入，存在 Cookie 失效、接口变动、极端情况下账号风控的风险。降低风险的用法：仅本机自用、避免高频轮询大目录、不要分享挂载服务给别人用。本方案的所有扫描都带了节流参数。

② 方案 A：OpenList 直链 + PotPlayer（主线，约 10 分钟）

A-1. 安装 OpenList

1
下载 Windows 版：github.com/OpenListTeam/OpenList/releases → openlist-windows-amd64.zip，解压到如 C:\openlist。
2
在该目录打开终端，启动服务并设置管理员密码： 
cd /d C:\openlist
openlist server          :: 前台运行，保持窗口开着；首次会初始化数据
:: 另开一个终端窗口：
openlist admin set 你的密码
浏览器打开 http://127.0.0.1:5244，用 admin / 你刚设的密码 登录。

A-2. 添加夸克网盘存储

3
网页：管理 → 存储 → 添加，按下表填写：
字段填什么说明
驱动夸克（Quark）—
挂载路径/quark自定义，后面脚本默认按它写，改了要同步改 config.ps1
Cookie见下方获取方法核心凭据
根文件夹 ID0挂整个网盘；只挂某文件夹就填地址栏里那串 id
启用签名关闭（仅本机自用）关掉后直链不带 sign，PotPlayer/协议/双击才能直接播；若要暴露到局域网请开启并只用脚本生成的链接
Web 代理 / 直链策略优先 302 重定向（不勾“Web 代理”）302 = 播放器直连夸克 CDN，不吃本机带宽；“本地代理”只在 302 失败时兜底
4
获取 Cookie：Edge/Chrome 打开 pan.quark.cn 并登录 → 按 F12 → 「网络/Network」标签 → 刷新页面 → 随便点一个请求（如 system_path?pr=ucpro 开头）→ 「请求标头」里复制完整的 cookie: 值 → 粘贴到存储配置的 Cookie 框 → 保存。 状态显示 work 即成功。
5
验证直链：回到首页点进夸克 → 找一个视频 → 右键「复制链接-下载链接」，得到形如 http://127.0.0.1:5244/d/quark/电影/xxx.mkv?sign=… 的地址。 注意：/d/ 后面必须带挂载路径（本例即 /d/quark/…），少了一级会 401。

A-3. PotPlayer 配置

6
播放直链：PotPlayer 主界面右键 → 打开 URL（Ctrl+U）→ 粘贴直链 → 播放。 或命令行：PotPlayerMini64.exe "http://127.0.0.1:5244/d/quark/电影/xxx.mkv?sign=…"
7
网络缓冲调大（边下边播顺滑的关键，按 F5 进选项）：
位置设置建议值
滤镜 → 源滤镜/分离器文件/流缓存512～1024 MB（内存 8G+ 再开这么大）
网络网络流缓冲时间默认 5000ms → 10000～15000ms
视频 → 视频渲染器硬解开启 DXVA/D3D11VA，降低 CPU 占用
基本记忆播放位置开启（OpenList 不记进度，靠 PotPlayer 补）

不同 PotPlayer 版本菜单位置略有差异，认准关键词“缓存 / 缓冲”。

③ 方案 B：rclone 挂载成盘符（要“双击就播”再做）

B-1. 安装两个组件

winget install WinFsp.WinFsp
winget install Rclone.Rclone
:: 装完 WinFsp 建议重启一次；rclone 要新开终端才进 PATH

B-2. 一键挂载（我已写好脚本）

cd /d "%USERPROFILE%\quark-potplayer\scripts"
:: 先编辑 config.ps1 里的 OpenListUser / OpenListPass
powershell -NoProfile -ExecutionPolicy Bypass -File mount-quark.ps1

脚本会自动创建 rclone remote（openlist → WebDAV http://127.0.0.1:5244/dav）并挂载 openlist:/quark 到 Z:。关键参数及理由：

参数值为什么
--vfs-cache-mode writeswrites支持随机 seek（拖进度条），比 minimal 顺滑；只缓存读过的片段，不会整片下载
--vfs-read-chunk-size32M（上限 1G）首块小=起播快，后续块翻倍=高码率跟得上
--buffer-size64M内存预读，扛网络抖动
--dir-cache-time15s新文件 15 秒内出现在盘里
--vfs-cache-max-size / max-age20G / 6h限制缓存占盘，自动清理

挂好后：资源管理器打开 Z:\ → 双击任意视频 = PotPlayer 直接开播；同名 srt/ass 字幕放在同一文件夹会自动加载。

B-3. 开机自动挂载

1
按 Win+R → 输入 shell:startup → 回车。
2
把 scripts\mount-autostart.bat 的快捷方式放进去。这样开机后 Z: 盘直接可用，双击即播。（OpenList 无需开机自启：QuarkPlay 桌面应用打开时会自动拉起服务。）

④ 方案 C：CloudDrive2（不想碰命令行）

官网 clouddrive2.com 下载 Windows 版 → 注册 → 添加云存储 → 选夸克网盘 → 粘贴网页版 Cookie → 挂载为盘符。之后和方案 B 的使用体验一致（双击即播、字幕自动加载）。它自带 WebDAV 服务（http://127.0.0.1:19798），还能反哺给电视/手机播放器用。完整功能需订阅，价格以官网为准。

5.1 监听网盘新增视频并自动播放

cd /d "%USERPROFILE%\quark-potplayer\scripts"
:: 一次性：扫最近 24h 的新视频，有就弹 PotPlayer
powershell -NoProfile -ExecutionPolicy Bypass -File watch-new.ps1

:: 常驻监听（每 60s 扫一次，Ctrl+C 停止）
powershell -NoProfile -ExecutionPolicy Bypass -File watch-new.ps1 -Watch

:: 自定义“新”的定义 / 只生成列表不开播
powershell ... -File watch-new.ps1 -Hours 48
powershell ... -File watch-new.ps1 -NoOpen

原理：调 OpenList API 递归列出 config.ps1 里 $ScanDirs（默认整个网盘，深度 4 层），对比本地已看记录（seen-videos.txt）+ 修改时间，新文件写进 m3u（自动携带签名参数）。扫描有节流（默认 60s 一轮），避免触发风控。

5.2 双击即播的两种形态

形态做法适合
实体文件双击（推荐）先按方案 B 挂出 Z: 盘 → PotPlayer 按 F5 → 基本 → 关联 → 勾选 mkv/mp4/ts 等扩展名 → 应用。之后 Z 盘里双击就是 PotPlayer。浏览、整理、选片
协议链接双击双击导入 register-quarkplay.reg → 之后任何地方出现 quarkplay:/quark/路径/文件.mkv 链接（浏览器、脚本、生成的 .url 快捷方式），点击即播。前提：存储设置里关闭了“启用签名”。未挂盘时用脚本/快捷方式直达

例如给某部电影生成桌面快捷方式：右键桌面 → 新建快捷方式 → 位置填 quarkplay:/quark/电影/沙丘2.mkv，以后双击这个图标直接开播。

⑥ 适用条件与限制

支持范围

项说明
网盘类型本方案主打通配：OpenList 支持夸克 / 阿里 / 百度 / 115 / 天翼 / 迅雷 / 123 等 30+ 网盘，加一个存储就多一个源；CloudDrive2 同理。换网盘不用换方案。
账号夸克非会员下载限速，边下边播 1080P 都会卡；SVIP 才有实用价值（你已是 SVIP ✔）
文件格式mkv/ts/m2ts 最适合流式播放（索引在头部，seek 快）；mp4 要求 moov 在文件头（faststart 封装），否则要等全片索引；蓝光原盘 BDMV 结构建议用方案 B 挂载后再播

带宽与清晰度（直链 302 = 直连夸克 CDN，SVIP 满速）

内容所需稳定带宽校园网可行性
1080P H.2648～12 Mbps（1～1.5 MB/s）轻松 ✔
1080P HEVC4～8 Mbps轻松 ✔
4K HEVC / HDR25～80 Mbps看校园网出口，高峰期可能顶不住
60～80G 蓝光原盘 remux40～100 Mbps建议挂载 + 大缓存，或先转码版观看

字幕

  • 方案 B（挂载）：srt/ass 与视频同名放同一网盘文件夹 → PotPlayer 自动加载 ✔（最省心）
  • 方案 A（直链）：URL 播放不会自动找网络字幕 → 把 srt 从 OpenList 网页下载后拖进 PotPlayer 窗口即可；在线匹配字幕功能照常可用

⑦ 常见失败与排查

现象原因解决
OpenList 存储状态不是 work / 列表为空Cookie 失效或复制不全重新 F12 抓完整 Cookie（注意要登录态下抓）；检查根文件夹 ID
PotPlayer 打开直链报 401/403①“启用签名”开着但链接没带 sign；②链接少了一级挂载路径（/d/ 后必须紧跟 /quark）关掉签名（本机自用）；或改用 watch-new.ps1 生成的链接（自动带 sign 和完整路径）
起播要等十几秒mp4 的 moov 在尾部，或首块太大换 mkv/ts 源；或把 --vfs-read-chunk-size 降到 16M
拖进度条黑屏很久 / 卡死缓存模式或缓冲不够确认 --vfs-cache-mode writes；PotPlayer 文件/流缓存调到 512M+
4K 频繁缓冲带宽不够或走了本地代理确认存储用的是 302 直链不是“Web 代理”；关掉“使用转码地址”外的多余代理；或降清晰度
rclone 报 mount: error: WinFsp not foundWinFsp 没装或没重启winget install WinFsp.WinFsp 后重启电脑
Z: 盘看不见rclone 退出了 / OpenList 没在跑先开 OpenList（5244 能访问），再跑 mount-quark.ps1
watch-new.ps1 报 Login failedconfig.ps1 密码不对改成 openlist admin set 设置的密码
Cookie 过期（几天到几周不等）夸克服务端会话失效重新抓 Cookie 更新；这是第三方方案的固有代价
突然全部 429 / 接口报错触发夸克风控（请求太频繁）调大 $PollSeconds、缩小 $ScanDirs 范围、少开并发；停几小时再试
某天驱动整体失效夸克改了接口升级 OpenList（GitHub releases）或 CloudDrive2；社区通常几天内适配
✔ 建议落地顺序
① 装 OpenList + 加夸克存储（10 分钟）→ ② PotPlayer 打开一条直链验证边下边播 → ③ 导入 watch-new.ps1 自动追更 → ④ 想要双击体验再装 WinFsp+rclone 挂 Z: 盘并设自启。全程免费，付费只有 CloudDrive2 这一个可选项。
